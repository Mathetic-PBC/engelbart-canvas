Mappings of Electron mechanics (recorded once here):
- `fetch` → `HTTPClient` protocol (`URLSessionHTTPClient`: ephemeral session, no cookies = `credentials: 'omit'`;
  `redirect: 'follow' | 'manual' | 'error'` via the task delegate; per-request timeout; `maxBytes` cap while streaming).
  Tests use fakes or loopback servers only.
- `safeStorage` → `SecretCrypt` (`KeychainCrypt`: an AES-GCM key kept in the macOS Keychain, service
  "Engelbart Swift Safe Storage", account "safe-storage"; the token/key files keep Electron's format, their secret
  fields base64 of the sealed box). The same file per data root as Electron (`<dataRoot>/github.json`, `zotero.json`):
  test mode's root keeps its own sign-in. A file sealed by Electron's safeStorage does not open with this key: signed out.
- `http.createServer(0, '127.0.0.1')` → `LoopbackServer` (Network.framework `NWListener`, 127.0.0.1 only, port 0).
- `shell.openExternal` → `NSWorkspace.shared.open` through the app-provided `openExternal` closure.
- IPC channel handlers → methods of `GithubChannels`, `ZoteroChannels`, `AgentMapChannels`; main→renderer sends →
  `EventHub` posts under the same channel names (`engelbart:github`, `engelbart:zotero`, `engelbart:zotero-finding`,
  `engelbart:zotero-waiting`, `engelbart:zotero-downloaded`, `engelbart:agent-run`, `engelbart:chat-benchmark`,
  `engelbart:agent-reveal`, `trace:entry`).
